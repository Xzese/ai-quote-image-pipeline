# Code of Conduct

This project is a professional, respectful space. Harassment, personal attacks,
discriminatory language, or aggressive behavior are not acceptable.

Expected behavior:

- Be respectful and inclusive.
- Keep feedback specific and constructive.
- Focus on the code and problem, not the person.
- Protect user and collaborator privacy.

Unacceptable behavior:

- Threats, abuse, sexual content, or targeted harassment.
- Sharing private information without consent.
- Posting or threatening to post abusive or confidential content.

For serious violations, contributors can ask a maintainer to:

1. Request immediate tone correction.
2. Pause participation and remove harmful content.
3. Remove abusive comments and restrict access where needed.

By participating in this repository, you agree to these expectations.
